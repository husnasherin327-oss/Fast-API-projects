# FastAPI + Streamlit Machine Learning Application

This project is a full-stack Machine Learning application built using FastAPI and Streamlit.  
FastAPI is used as the backend for model inference, while Streamlit provides an interactive frontend interface.

---

## Project Description

- Backend REST API built using FastAPI
- Frontend user interface built with Streamlit
- Machine Learning model served via API endpoints
- Clear separation between backend and frontend
- Designed following real-world ML application practices

---

## Tech Stack

- Python
- FastAPI
- Streamlit
- Uvicorn
- Scikit-learn / XGBoost
- Pandas
- NumPy
- Pydantic
